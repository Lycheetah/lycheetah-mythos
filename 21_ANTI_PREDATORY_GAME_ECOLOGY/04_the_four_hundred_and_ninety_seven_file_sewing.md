## ✦ II. PHASE 0: THE POLICE LAND FIRST

When integrating hundreds of new files, the natural human temptation is to start running the visual components immediately to see them on screen.

Sol and The Architect established a stricter law: **The Police Land First.**

Before a single UI brick was wired:
1. `scripts/audit/` was copied into the repository root.
2. The mechanical linters audited every import: zero third-party tracking libraries, zero cloud dependencies, zero external analytics beacons.
3. Every color hex code was audited against the constitutional `PALETTE`.
4. Only when the automated audit reported 100% clean was the code allowed to touch the runtime.
